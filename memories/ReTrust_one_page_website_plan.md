# ReTrust 一頁式網站製作計劃

## 品牌資訊

- 品牌名稱：ReTrust
- 品牌理念：Re（Recycle/Re-use/Resell）+ Trust（信任）
- 中文諧音：「認真」，代表對每一件二手物品的鑑定與服務都認真看待。
- 主要功能：官方二手、C2C 二手、出租平台、官方論壇

## 專案目標

1. 使用 HTML + Bootstrap + jQuery 建置一個一頁式網站。
2. 以 ReTrust 的品牌理念為核心，結合「永續、信任、嚴謹鑑定」的視覺與內容。
3. 描述並展示「官方二手」「C2C 二手」「出租平台」「官方論壇」等主要功能。
4. 以直觀一頁式瀏覽，讓使用者快速了解品牌、功能、流程與如何參與。

## 目標使用者

- 尋找安心二手商品的買家
- 想快速上架、變現閒置物品的賣家
- 希望租借短期所需商品的使用者
- 想參與討論、分享心得的社群成員

## 技術與架構

- HTML：使用語意化標籤結構頁面內容。
- Bootstrap：快速建置響應式排版、導航列、卡片、按鈕、表格等 UI 元素。
- jQuery：
  - 控制頁面捲動、選單錨點跳轉。
  - 交互效果（Tab 切換、輪播、自動計數、按鈕動畫）。
  - 表單驗證與簡單互動。

## 一頁式網站區塊規劃

1. 導覽列（Navbar）
   - 置頂固定 `sticky-top`
   - 區塊連結：首頁、品牌理念、官方二手、C2C、出租、論壇、聯絡。
   - 搭配品牌 Logo & 按鈕 CTA。

2. 英雄區 Hero Section
   - 大型主標語：`ReTrust：讓每一件二手好物，被認真看見。`
   - 副標語：`正式驗證 x 安全交易 x 快速上架，一個懂你的循環平台。`
   - 主要 CTA：`探索官方二手`、`我要上架`。
   - 背景使用高質感二手生活情境圖片或漸層色塊。

3. 品牌理念區 Value Proposition
   - 說明 ReTrust 的 `Re` 與 `Trust` 精神。
   - 以三個重點呈現：
     - `Recycle`：延續物品生命
     - `Re-use`：重複使用更有價值
     - `Resell`：安全轉手、安心交易
   - 加入「認真鑑定」與「信任保障」說明句。

4. 主要功能介紹
   - 4 個功能卡片：官方二手、C2C 二手、出租平台、官方論壇。
   - 每張卡片說明目的、核心優勢、使用者受益。
   - 加入簡單圖標與短文案。

5. 服務區塊：官方二手 vs C2C 二手 vs 出租
   - 使用 Bootstrap 的 Tab 或 Accordion，讓使用者快速切換查看不同服務。
   - 官方二手：由平台鑑定、保固、官方出品
   - C2C 二手：個人賣家上架、平台仲介、雙方信任
   - 出租平台：短期租借、押金安全、便利歸還

6. 流程說明（How It Works）
   - 針對買家、賣家、出租者分別設計 3 步驟。
   - 使用圖示卡片呈現流程：
     - 賣家：拍照上架、審核上架、待售成交
     - 買家：搜尋商品、下單付款、安心取貨
     - 出租者：刊登出租、確認租期、交付歸還

7. 熱門推薦區 / 特色商品展示
   - 使用 Bootstrap 卡片展示三到四個示範商品。
   - 每張卡片顯示商品名稱、成色、價格、類別、按鈕。
   - 可搭配簡單 hover 特效或快速收藏按鈕。

8. 特色亮點區（Trust & Safety）
   - 列出平台優勢：
     - `官方鑑定`、`安心金流`、`快速上架`、`會員評價`
   - 使用 Icon 與短文案呈現。

9. 官方論壇介紹
   - 說明論壇用途：
     - 二手好物分享、租賃經驗交流、商品鑑定討論、社群活動公告。
   - 提供論壇分區構想：`尋寶分享`、`鑑定諮詢`、`租借心得`、`平台公告`。

10. 常見問題區（FAQ）
    - 使用 Accordion 展開式設計。
    - 主要問題如：
      - `官方二手與 C2C 有何差異？`
      - `我要如何租借商品？`
      - `我的商品如何上架？`
      - `退款與退貨如何處理？`

11. CTA 區 / 聯絡區
    - 重點邀請：`現在就加入 ReTrust，讓二手變成新選擇。`
    - 留下簡單聯絡表單或 Email/社群連結。
    - 放置 `回到頂端` 按鈕。

## UX 與風格建議

- 色調：綠色系與米色搭配，傳遞環保、信任與質感。
- 字體：簡潔現代、中文搭配圓潤無襯線字體。
- 版面：保持留白、區塊明確、行動呼籲清楚。
- 圖片：優先選用高質感二手商品、生活場景、分享與社群互動照。
- 響應式：使用 Bootstrap 的網格系統，在行動裝置上維持單欄堆疊、按鈕易操作。

## 互動與 jQuery 功能

- 導覽列錨點平滑滾動。
- Tab 切換與 Accordion 展開。
- 英雄區按鈕點擊後自動捲動到對應區塊。
- FAQ 與服務卡片 hover 動效。
- 特色數據計數動畫（如網站已累計上架商品數、成交筆數）。
- 簡單的表單驗證提示（例如 Email 格式、必填欄位）。

## 開發建議步驟

1. 建立 `index.html` 並引入 Bootstrap CSS、Bootstrap JS、jQuery。
2. 設計頁面結構：`navbar`、`hero`、`section`、`footer`。
3. 使用 Bootstrap Grid 與 Card 組件完成各區塊。
4. 撰寫自訂 CSS，調整色彩、間距、按鈕樣式與微動畫。
5. 以 jQuery 增加互動：平滑滾動、Tab 切換、FAQ 展開、資料計數動畫。
6. 測試桌面與行動裝置版型，確保一頁式導覽順暢。
7. 最後補上品牌文案、功能說明、論壇與出租平台特色。

## 產品定位摘要

ReTrust 是一個「兼具官方鑑定信任感與社群二手交易活力」的一頁式品牌網站。透過明確的功能分區與品牌理念傳達，讓使用者一眼看懂：

- 這裡有官方把關的二手好物
- 也有 C2C 自由刊登與出租服務
- 還有官方論壇能交流鑑定、分享與討論
